## Summary
s14 在 s13 后台任务的基础上，增加了"时间触发"能力——把未来要执行的意图记下来，等 cron 表达式匹配时再触发。调度器定时检查所有记录，时间到了就把 prompt 注入通知队列，由主循环决定如何处理。核心区分：后台任务是"等结果"，定时调度是"等开始"。

## Key Claims
- 调度记录持久化存储，重启后仍有效
- cron 表达式指定触发时间，检查器每分钟遍历一次
- 触发后不是默默执行，而是先发通知给主循环
- 调度系统和后台任务系统共享通知队列，统一注入主循环

## Key Quotes
> "定时调度并不是另一套 agent。它最终还是回到同一条主循环。"
> "调度器做的是'记住未来'，不是'取代主循环'。"
> "后台任务是在'等结果'，定时调度是在'等开始'。"
