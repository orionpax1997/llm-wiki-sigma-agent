## Definition
Anthropic 是 Claude 系列模型的开发公司，也是 Claude Code 的背后公司。

## Key Facts
- 开发 Claude 系列 LLM（Claude 3.5 / 4.x）
- 开发 Claude Code（AI 编程工具）
- 开发 MCP（Model Context Protocol）协议
- 创始成员曾参与 Transformer 架构研究
